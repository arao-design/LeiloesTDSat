# LeiloesTDSat

## Sobre o Projeto
O LeiloesTDSat é um sistema desktop desenvolvido em Java para o gerenciamento e controle de leilões de produtos. A aplicação permite o cadastro de novos itens de leilão, visualização de produtos cadastrados em formato de tabela, além de controle de status e lances.

## Tecnologias Utilizadas
* **Linguagem:** Java (com Swing para interface gráfica)
* **Banco de Dados:** MySQL (utilizando JDBC e padrão DAO/DTO)
* **Ambiente de Desenvolvimento:** Apache NetBeans IDE
